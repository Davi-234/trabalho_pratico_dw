# Descrição:
Este repositório é um trabalho para a disciplina de DW (Desenvolvimento Web) 1, que possui o objetivo de desenvolver as habilidades aprendidas durante as aulas, sobretudo, acerca de: layouts responsivos, armazenamento local (LocalStroage) e manipulação do DOM.

## Foram pedidos três aplicações diferentes:

### Calculadora: 
Essa aplicação é uma calculadora responsiva, que realiza aritmética básica e conversão de bases numéricas, além de subtração e soma de bases numéricas.

### Lista de Afazeres (ToDo List):
Essa aplicação tem o objetivo de representar uma lista de afazeres, tendo sido baseada no Templete de "Tusharnankani" - acesso no link: https://github.com/tusharnankani/ToDoList -, porém, foi adaptada para representar uma agenda de limpezas de uma empresa de faxinas. 
Com cada 'bloco' de faxina contendo: o endereço da faxina, o nome do cliente e a data marcada.

### Aplicação de Alfabetização:
Essa Aplicação simula um EdTech para alfabetização, a aplicação permite a entrada com teclado pelo usuário, a tecla pressionada aparece na tela, e então é utilizado um sintetizador de voz para emitir o som da letra, em caso de ser uma vogal, é mostrado uma imagem de uma palavra que comece com essa vogal.
